# Fotos de produtos

Fotos coletadas **manualmente pela equipe** (divulgação das marcas / sites oficiais), em 26/10/2026, para a **demonstração** do hackathon.
Os direitos pertencem às marcas e aos fotógrafos. Uso restrito a este protótipo, com repositório privado.
**Antes de qualquer uso público, substitua por fotos com licença ou autorização.**

Nome do arquivo = id do produto no catálogo (`cos-…` cosméticos, `med-…` medicamentos). O arquivo é convertido para JPEG.
